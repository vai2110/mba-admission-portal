Student FAQs

Can I use this tool below 75 percentile?

No. This version intentionally starts at 75 because the goal is to compare 75+ cutoff opportunities rather than create a broad low-cutoff directory.

Why does the same college appear more than once?

A college can have different cutoffs for different programmes, so programme-specific rows are kept separate where the source provides them.

Why are some cutoffs marked expected?

Many institutes do not publish a fixed percentile before the admission cycle. Those rows are shown as expected/indicative rather than being presented as official.

Why is NMAT different?

NMAT institutes frequently publish score thresholds. The tool converts those scores to the current GMAC percentile-ranking reference so you can still use one percentile filter across exams.
