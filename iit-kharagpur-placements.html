How Students Should Read the Placement Report

  1. Start with the latest audited or official placement report.
  2. Compare average and median CTC rather than only the highest package.
  3. Check batch size and number of participating companies.
  4. Review sector and role distribution.
  5. Separate institute-wide figures from programme-specific outcomes.

Frequently Asked Questions

Which placement figure matters most?

For comparing typical outcomes, median CTC is often more informative than the highest package. Average CTC adds a second useful benchmark.

Are these placement numbers guaranteed for every student?

No. Placement outcomes vary by role, sector, student profile and recruitment cycle. Published figures describe the reported batch outcome.

Why are some years marked unavailable?

The page uses official sources only. Where the retrieved official archive did not state a comparable salary figure, the value is not filled with an estimate.
