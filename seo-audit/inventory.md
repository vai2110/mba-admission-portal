# CollegeDecoded URL inventory

This file is generated during the Vercel build by `scripts/generate_seo_inventory.py`.

The build-generated report contains one row per repository HTML route with:
URL, visible word count, title, meta description, canonical URL, sitemap membership, inbound internal-link count, and duplicate-cluster ID.

## Baseline before regeneration

- Root-level HTML files observed: 667.
- Sitemap URLs observed in the inspected revision: 668.
- Historical technical audit: 668 pages checked, 46 with issues.
- Historical internal-link audit: 664 pages checked, 49 zero-incoming pages, 85 college clusters, 31 reciprocal-link gaps.

The historical JSON audit files are snapshots dated October 2026. The generated inventory is the authoritative per-route view for this branch preview. Duplicate-cluster IDs are candidate groupings only. Redirect winners require review of page content and source evidence before redirects are added.
